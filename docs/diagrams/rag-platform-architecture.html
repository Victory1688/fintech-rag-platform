金融信贷企业级 RAG 知识库平台 · 部署架构图

五个网络域：外部/办公网 · DMZ 边界 · SF 可信域 · 数据区 · 可观测区（独立网段）　|　 入口路径 Web → Nginx → rag-gateway；内网业务走 Feign 直连、不经 DMZ。
DMZ 边界（不可直达内网引擎） 业务微服务（6 个，可独立部署） 检索/模型引擎（仅内网可达） 数据区（MySQL / Redis / MinIO / MQ） 可观测区（独立网段）
提示：SVG 可直接拖进 PPT / Word / Visio，放大不失真。
