五个网络域：外部/办公网 · DMZ 边界 · SF 可信域 · 数据区 · 可观测区（独立网段）　|　 线型按语义着色，图例已画进图里，导出 SVG / PNG 均自带。
读懂这张图的关键：「内网 Feign 直连 · 不经 DMZ」（红色粗实线）与 「Prometheus 拉取」（青色点线）是两类完全不同的流量 —— 前者是内网业务微服务绕过边界网关直达可信域，是安全设计的核心； 后者是监控系统主动拉指标（Prometheus 是 pull 模型，不经 Collector 转发）。 线型与颜色均已区分，图例见图片底部。
